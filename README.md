# Проект 1. «5 букв»

Консольная игра в духе Wordle. Программа загадывает слово из 5 русских букв,
у игрока 6 попыток. После каждой попытки — подсказка по буквам:

```text
Загадано: озеро
Ввод:     арбуз
Результат: ❌🟡❌❌🟡

✅ буква на месте   🟡 есть, но не там   ❌ буквы нет
```

Задание разбито на три merge request'а. Делай их по очереди.

---

## Быстрый старт

```bash
./gradlew run     # запустить программу
./gradlew check   # тесты и линтеры — ровно то, что проверяет CI
```

Нужен **JDK 25 или новее**. Gradle ставить не нужно — в проекте лежит `gradlew`,
он скачает нужную версию сам.

## Что реализовано

- **MR1:** загрузка словаря, выбор ответа по `seed` и сессия с числом и историей
  попыток, загаданным словом и статусом игры. Словарь читает отдельный
  `DictionaryLoader`, игровое состояние хранит `GameSession`.
- **MR2:** `GameService` проверяет длину, буквы и наличие слова в словаре,
  сравнивает буквы с учётом повторений и определяет победу или поражение.
  Ошибочный ввод не расходует попытку. Правила игры не зависят от консоли.
- **MR3:** `ConsoleWork` показывает меню, принимает ввод и выводит результаты.
  Можно сыграть несколько партий подряд. Неверный пункт меню не завершает
  программу. Параметр `--seed` делает выбор ответов воспроизводимым.

## Дополнительные возможности

- Выбор сложности и категории: лёгкий, обычный, сложный, животные, еда,
  природа. По умолчанию выбран обычный режим. Для каждого режима есть отдельный
  файл с возможными ответами; соответствие названий и путей задано в `Main`.
- Общий `dictionary.txt` всегда используется для проверки попыток. В
  `GameService.startGame` отдельно передаются словарь допустимых слов и набор
  ответов выбранного режима. Поэтому ответ ограничен режимом, а вводить можно
  любое слово из общего словаря.
- Подсказка `?` открывает одну букву и её позицию; за партию её можно получить
  один раз. Есть выбор цвета текста в консоли.
- `GameStatistic` отдельно хранит статистику за текущий запуск: победы,
  поражения, среднее и минимальное число попыток в выигранных партиях.
  Статистика доступна из меню и не сохраняется между запусками.

## Принятые решения

- Загрузка файлов вынесена в `DictionaryLoader`, правила — в `GameService`,
  состояние партии — в `GameSession`, ввод и вывод — в `ConsoleWork`. Так игру
  можно проверять тестами без работы с консолью, а каждому классу остаётся
  понятная задача.
- Словарь попыток и набор ответов разделены: маленький тематический набор
  меняет только то, что может быть загадано, но не запрещает остальные слова
  при угадывании. Наборы ответов хранятся в обычных текстовых файлах, чтобы
  добавлять и менять их без изменения правил игры.
- Сложность и категория выбираются одним пунктом меню, потому что одновременно
  они не применяются. При запуске выбран обычный режим, поэтому можно сразу
  начать игру. `seed` задаётся необязательным аргументом запуска: обычному
  игроку вводить его не нужно, а тесты могут воспроизвести партию.
- Статистика существует только в памяти текущего запуска: постоянное
  хранилище для этой консольной игры не требуется.

## Тесты

Реализованы обязательные тесты MR1–MR3. В `MenuTest` четыре проверки:
неверный пункт меню, две партии подряд, одинаковый вывод с фиксированным
`seed` и выбор режима без ограничения словаря допустимых попыток. Также добавлены
тесты начального состояния `GameSession` и неположительного числа попыток.

Запуск всех тестов и проверок стиля: `./gradlew check` (Windows:
`.\gradlew.bat check`).
