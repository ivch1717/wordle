# Wordle — «5 букв»

Консольная игра на Java по мотивам Wordle: нужно угадать слово из пяти русских букв за шесть попыток. После каждого хода игра показывает, какие буквы стоят на своих местах, какие встречаются в слове и каких в нём нет.

## Возможности

- Шесть попыток на партию и подсказки для каждой буквы:
  - ✅ — буква на своём месте;
  - 🟡 — буква есть в слове, но находится на другой позиции;
  - ❌ — для этой буквы нет совпадения с учётом уже найденных вхождений.
- Корректное сравнение слов с повторяющимися буквами.
- Проверка длины, буквенного состава и наличия слова в словаре. Некорректный ввод не расходует попытку; регистр букв не имеет значения.
- Три режима сложности: лёгкий, обычный и сложный.
- Тематические наборы слов: животные, еда и природа.
- Подсказка по команде `?`: открывает одну букву и её позицию. Доступна один раз за партию и не расходует попытку.
- Несколько партий подряд без перезапуска приложения.
- Статистика побед и поражений, среднего и минимального числа попыток в выигранных партиях.
- Выбор цвета текста в консоли.
- Воспроизводимый выбор слов с помощью параметра `--seed`.

Статистика хранится в памяти и сбрасывается при выходе из приложения.

## Быстрый старт

### Требования

- **JDK 25 или новее**.
- Переменная `JAVA_HOME` должна указывать на установленный JDK.
- Интернет для первой загрузки Gradle и зависимостей.

Устанавливать Gradle отдельно не нужно: в репозитории есть Gradle Wrapper.

### Windows / PowerShell

```powershell
git clone https://github.com/ivch1717/wordle.git
cd wordle
.\gradlew.bat run
```

### Linux / macOS

```bash
git clone https://github.com/ivch1717/wordle.git
cd wordle
./gradlew run
```

Запускайте команды из корня проекта: приложение читает словари из `src/main/resources/`.

Для запуска из IntelliJ IDEA откройте проект как Gradle-проект, выберите JDK 25+ в настройках Gradle JVM и выполните задачу `run`.

### Запуск с фиксированным seed

Позволяет повторить последовательность загаданных слов при одинаковом выборе режимов и порядке партий.

Windows:

```powershell
.\gradlew.bat run --args="--seed 42"
```

Linux / macOS:

```bash
./gradlew run --args="--seed 42"
```

## Как играть

После запуска доступно меню:

```text
1. Новая игра
2. Выбор цвета вывода
3. Статистика
4. Выбрать режим сложности/категорию слов
0. Выход
```

По умолчанию выбран обычный режим. Начните новую игру и вводите слова из пяти букв. Для подсказки введите `?`. После победы или поражения приложение вернётся в меню.

Режим определяет набор возможных ответов. При этом для угадывания можно использовать любое слово из общего словаря — оно не обязано относиться к выбранной теме.

## Архитектура

Игровая логика отделена от консольного ввода и вывода, поэтому правила можно тестировать независимо от интерфейса.

| Класс | Ответственность |
|---|---|
| `Main` | Точка входа, обработка `--seed` и настройка режимов |
| `DictionaryLoader` | Чтение словарей в UTF-8 и проверка длины слов |
| `GameService` | Выбор ответа, валидация попыток, сравнение букв и определение результата |
| `GameSession` | Состояние партии, история ходов, число попыток и статус игры |
| `ConsoleWork` | Меню, ввод слов, подсказка и оформление вывода |
| `GameStatistic` | Статистика завершённых партий |

Общий словарь допустимых попыток и наборы ответов для отдельных режимов хранятся раздельно. Это позволяет добавлять слова и менять тематические наборы без изменения правил игры.

## Тестирование и качество кода

Тесты проверяют загрузку словаря, начальное состояние партии, валидацию ввода, обработку повторяющихся букв, победу и поражение, воспроизводимость по seed и сценарии работы меню. Консольные сценарии проверяются запуском приложения в отдельном процессе.

Запуск тестов:

```powershell
.\gradlew.bat test
```

Все проверки, включая тесты, стиль и форматирование:

```powershell
.\gradlew.bat check
```

Автоматическое форматирование:

```powershell
.\gradlew.bat spotlessApply
```

В Linux / macOS используйте `./gradlew` вместо `.\gradlew.bat`.

После запуска тестов доступны HTML-отчёты:

- Результаты тестов: `build/reports/tests/test/index.html`.
- Покрытие JaCoCo: `build/reports/jacoco/test/html/index.html`.
